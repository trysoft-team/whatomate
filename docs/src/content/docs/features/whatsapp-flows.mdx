## Overview

WhatsApp Flows enable businesses to create rich, interactive experiences directly within WhatsApp. Unlike regular messages, Flows provide native UI components like forms, dropdown menus, and multi-screen journeys.

## Flow Builder

![WhatsApp Flow Builder](/whatomate/images/10-whatsapp-flow-builder.png)

Whatomate provides a visual Flow Builder to design and manage your WhatsApp Flows:

### Features

- **Visual Editor** — Design flows with a drag-and-drop structure panel
- **Screen Builder** — Create multi-screen experiences
- **Full Meta component library** — Text, inputs, media uploads, carousels, navigation lists, If/Switch logic, and more
- **Interactive playground** — Preview screens like Meta’s Flow playground (form values drive If/Switch branches live)
- **Live Meta rule validation** — Component limits and exclusivity rules are checked as you edit; save is blocked until errors are fixed
- **Synced flows stay editable** — Flows pulled from Meta unwrap correctly for editing and re-wrap when you save
- **Sync with Meta** — Push and pull flows from Meta; duplicate a published flow to revise it as a draft

## Flow Lifecycle

<Steps>

1. **Create**

   Design your flow using the visual builder (or generate a draft with AI), then edit screens and components.

2. **Save to Meta**

   Push your flow to Meta's WhatsApp Business API.

3. **Test**

   Use the in-builder playground, then test the flow in draft mode on Meta before publishing.

4. **Publish**

   Make the flow available for use in messages.

</Steps>

## Flow Status

| Status | Description |
|--------|-------------|
| **Draft** | Flow is being designed, not yet available |
| **Published** | Flow is live and can be sent to users |
| **Deprecated** | Flow has been retired |

### Editing a Published Flow

Publishing requires a **Draft** flow, so a flow that is already **Published**
or **Deprecated** can't be edited in place. To change one, use **Duplicate**:
it clones the flow into a fresh **Draft** copy (named "… (Copy)") with a new,
empty Meta flow ID. Edit the copy, save it to Meta, and publish it — leaving
the original untouched. This is the intended path for revising a live flow.

## Using Flows

### In Chatbot

Integrate WhatsApp Flows into your chatbot conversation flows:

1. Create a flow step with type "WhatsApp Flow"
2. Select the published flow
3. Configure the trigger message
4. Handle flow completion responses

### Via API

Send flows programmatically using the REST API:

```bash
POST /api/messages
{
  "contact_id": "...",
  "type": "flow",
  "flow_id": "...",
  "flow_token": "...",
  "header": "Complete Your Order",
  "body": "Please fill in the details below",
  "button_text": "Start"
}
```

## Best Practices

<Aside type="tip">
  Keep flows concise - users prefer shorter, focused experiences over lengthy multi-screen journeys. Watch the live validation banner for Meta caps (for example, 50 components per screen).
</Aside>

<Aside type="note">
  WhatsApp Flows require a business verification and may not be available in all regions.
</Aside>
