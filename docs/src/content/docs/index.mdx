## What is Whatomate?

Whatomate is a modern, open-source WhatsApp Business Platform built with Go and Vue.js. It ships as one binary with the web app embedded: run it, finish the setup wizard in your browser, and manage WhatsApp conversations, automation, campaigns, and calls for your whole team.

## Tech Stack

### Backend
- **Go 1.25+** with [Fastglue](https://github.com/zerodha/fastglue) (fasthttp-based HTTP framework)
- **PostgreSQL**, **MySQL / MariaDB** or **SQLite** (your choice) for data storage with GORM v2
- **Redis** (optional) for caching and pub/sub across servers; a built-in store is used otherwise
- **JWT** for authentication

### Frontend
- **Vue 3** with Composition API and TypeScript
- **Vite** for build tooling
- **shadcn-vue** / Radix Vue for UI components
- **TailwindCSS** for styling
